# Demo Script (about 12 minutes)

Before you start: import schema.sql or open the site once so the database is created, keep ACCOUNTS.txt open, use a desktop browser at 100% zoom, and have one student with data entered. Log in as admin in one browser window and as a student in a private window.

1. Public side (1 min). Show the landing page, then Register. Point out that new accounts wait for approval. Register a test student.
2. Approval (1 min). Admin window: the Approvals badge in the sidebar, approve the new student. Show that a teacher can approve students too but not teachers.
3. Account generator (2 min). Admin > Account generator > Many accounts. Paste five names, include one duplicate and one bad line. Preview, point out the numbering of the duplicate and the skipped line, Create, Download CSV. Sign in as one generated student to show the forced password change.
4. Programs (1 min). Admin > Programs. Show a 6-month Caregiving course and a 4-year degree. Edit one length. Show the Year level options follow it.
5. Prediction (3 min). Student window: Data Inputs, change attendance, then Predictions. Walk through the formula, trend and confidence. Flag a prediction. Admin > Grade Flags to resolve it. Admin > Subjects to show custom weights.
6a. Grading sheets (2 min). Admin > Grading Sheets. Filter by program and year level, show the Per subject sheet, the Consolidated sheet with GWA, then the Honors outlook with the reasons. Change a honor limit, show the outlook update, then Download Excel workbook and open it.
6. Model accuracy (2 min). Admin > Model Accuracy. Record final grades for one subject, then show average error, within 5 points, at-risk table and the CSV.
7. Profile and Settings (1 min). Show that Profile and Settings are the same page, change the theme to dark, show that the login page stays light.
8. Close (1 min). Reports, Activity Logs, backup. State the limitations in the overview before questions.
